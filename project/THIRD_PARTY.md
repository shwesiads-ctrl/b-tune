# Dependencies

JUCE 8.0.10 is downloaded during configure, not embedded in this source archive.
Review JUCE's license before distributing a product:
https://github.com/juce-framework/JUCE/blob/8.0.10/LICENSE.md

React, React DOM, Vite, TypeScript and their exact transitive versions are
recorded in Web/package-lock.json. Their licenses remain applicable.
Emscripten SDK 3.1.64 builds the browser DSP. Do not redistribute toolchains as
part of the plugin installer. No paid cloud API, account key or secret is used.
